Add a base path

An absolute directory on the host that FileHub may read. It has to exist on the server. Until it is granted to a user or a group only admins can see it — the Admin role is an implicit grant of every base path.

On a disk marked this way, every folder directly under it gets an info button with a poster and a summary. Looked up once, then kept.
